# FastSC

Modular Roblox Luau client with Moon UI.

Entry point: `loader.lua`. Game modules: `games/<slug>/script.lua`.

Selected experiences: Da Hood, Piggy, Arsenal, Murder Mystery 2, Build A Boat For Treasure, Legends of Speed, Break In, RIVALS, Blade Ball, Dead Rails, Ink Game.

The repository is currently private. Unauthenticated raw GitHub loading requires public visibility; do not embed GitHub access tokens in client scripts.

Implementation and validation details are recorded in this repository as the modular source is added.
